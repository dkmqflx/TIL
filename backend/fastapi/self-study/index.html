FastAPI 백엔드 개발자 되기

React·NestJS 개발자가 실무에 필요한 지식을 갖춘 FastAPI 백엔드 개발자로 전환하기 위한 갭 중심 10주 커리큘럼. 4개 강의를 종합·재구성했습니다.

PostgreSQL SQLAlchemy 2.0 asyncio Redis JWT / OAuth2 WebSocket pytest Docker / CI
학습 순서 추천: Week 1~3(기초)로 감을 잡고 → Week 4(⭐ 비동기 원리)를 반드시 이해한 뒤 → Week 5~7(DB · 구조화 · 비동기 통신)로 손에 익히고 → Week 8~9(⭐ 인증 · 실시간)까지 진행한 뒤 → Week 10(테스트 · 배포)으로 마무리하면 가장 잘 이어집니다.
